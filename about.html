About FreeZone

A simple website to discover free-to-play games.

Why this project?

There are many free games online but they are hard to find in one place. FreeZone uses the FreeToGame API to show games, filter by genre, search by name, and save favorites.

  • Game data loaded with fetch and async/await
  • Filter by genre and search by title
  • Favorites saved in localStorage
  • Play button opens the game website
